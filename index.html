Quick Setup

  1. ऊपर के ZIP को extract करें।
  2. index.html को Chrome में खोलें।
  3. फिर Google Sheet बनाकर Apps Script में Code.gs और Apps Script वाला Index.html लगाएँ।
  4. Initialize System चलाएँ।
  5. Contacts में official public emails डालें।
  6. पहले Drafts बनाकर जाँचें, फिर Send करें।
महत्वपूर्ण: केवल local HTML खोलने से Gmail को ईमेल भेजने की अनुमति नहीं मिलती। सुरक्षित mail delivery Google Apps Script के माध्यम से होगी।
